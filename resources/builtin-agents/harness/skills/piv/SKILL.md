# PIV workflow snapshot

1. Analyze the request and make acceptance criteria testable.
2. Plan dependency-ordered tasks with exact validation commands.
3. Implement production code through the coder role.
4. Author tests independently through the test-author role.
5. Ask the verifier to refute completion with gate evidence.
6. Ask the reviewer for a separate quality/security judgment.
7. Preserve all workspaces for human inspection and merge.
