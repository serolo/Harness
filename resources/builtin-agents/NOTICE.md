# Built-in agent attribution

Polly and Debby adapt the role decomposition and independent-response ideas from the
[Omnigent Polly](https://github.com/omnigent-ai/omnigent/tree/main/examples/polly) and
[Omnigent Debby](https://github.com/omnigent-ai/omnigent/tree/main/examples/debby) examples,
licensed under Apache-2.0. Their prompts and Harness configuration are newly authored for
Harness's supervised worktree, provider, and capability model.

No upstream unsandboxed execution policy, arbitrary MCP server, Python callable, shell tool,
environment injection, or autonomous merge authority is included. The Harness PIV built-in is
newly authored from this repository's documented workflow.
